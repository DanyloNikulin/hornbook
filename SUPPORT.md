# Support

Use [GitHub Discussions](https://github.com/DanyloNikulin/hornbook/discussions)
for setup questions, ideas and general help. Use an issue when you have a
reproducible product defect.

Before asking for help:

1. Run `hornbook doctor` and note which local tools are missing.
2. Check the application version and operating system.
3. Reproduce with a throwaway journal when possible.
4. Remove transcripts, lesson content, API keys and personal file paths from
   logs and screenshots.

Security problems belong in a private vulnerability report, as described in
[SECURITY.md](SECURITY.md).
